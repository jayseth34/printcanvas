# PrintCanvas

A static, browser-based design studio for preparing artwork on apparel mockups. Uploaded artwork stays in your browser; the site does not upload images to a server.

## Run locally

Open `index.html` in a modern browser. No build step or account is required.

## Features

- Upload browser-supported image formats, including PNG, JPG, and WebP.
- Preview designs on regular-fit and oversized T-shirt mockups, with color options.
- Sample a solid background color and remove it with adjustable tolerance.
- Adjust brightness, contrast, sharpness, scale, rotation, and placement.
- Export a JPG mockup, transparent PNG artwork, or PDF proof.

PDF export loads jsPDF from a CDN and requires an internet connection. Background cleanup and image adjustments run in the browser; they are not AI cutout or generative upscaling.
